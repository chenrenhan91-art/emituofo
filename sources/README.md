下载 URL 格式：`https://raw.githubusercontent.com/cbeta-org/xml-p5/master/T/T08/T08n0251.xml`（册号、经号相应替换）。在线阅读入口已显示于每篇经文下。

处理仅做繁简转换、按原标点分段，以及把咒文全角空格转换为诵读标点。原底本异体字保留，因此“揭帝／般罗／莎婆诃”等字形可能不同于常见流通本。校勘注、序文、卷名和附加仪轨不作为正文诵读。原始 XML 的出版说明要求非商业使用时保留文件头；本项目随附完整来源文件头及署名。

拼音由 pypinyin 生成，附加佛教词汇读音词典，逐字对齐。采用普通话标调，不是梵语复原，也不是某一寺院的唱诵音系。“一、不”等采用基本声调，实际语流可能变调。生僻字和特殊读音的合成输入替换仅作用于音频，不改变页面正文。AI 语音不能替代佛教语音专家的逐字审订。

语音：Microsoft Xiaoxiao Neural，速度 -18%，保持原音高，整段连续合成以保留语气和标点停顿，段间额外停顿 500 ms。每个音频文件名包含正文、发音输入与声音配置的内容摘要；`audio/verses.json` 保存逐段正文、合成输入与文件 SHA-256，避免沿用旧序号录音。

注释：全库1304段均配逐段白话说明，其中《地藏经》216段、《法华经》871段；两部长经另保留41品导读。注释为原创学习辅助，不替代原典或完整白话译本。`verse_notes.hashes.json` 与 `long_sutra_notes.json` 将逐段解释绑定到正文摘要；构建拒绝遗漏、空白或摘要错位。`chapter_guides.json` 的原文锚点在每次构建时校验。法华经第二十五品复用普门品同段注释。

重建：

```sh
python3 -m pip install -r scripts/requirements.txt
python3 scripts/build_corpus.py
python3 scripts/gen_chant.py
python3 scripts/verify_corpus.py
```

验证涵盖正文与底本全部汉字顺序一致、拼音逐字对齐、音频清单／摘要一致、全部音频可解码。抽样自动语音识别仅辅助发现读音问题，不等于真人审听。确认全部音频生成且验证通过后，才可部署。
